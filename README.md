# Vue.js Task Manager - TDD Unit Testing Suite

A modular Vue 3 application constructed using Test-Driven Development (TDD) principles with Vue Test Utils and Vitest.

## Environment Requirements

- Node.js (v18.0+)
- npm (v9.0+)

## Setup & Execution Instructions

1. **Install Dependencies:**
   ```bash
   npm install
   ```
   a.Run Unit Tests:
   ```bash
   npm run test:unit
   ```
   b.Start Development Server:

```bash
  npm run dev
```

c.Generate Test Coverage Report:

````bash
 npm vitest run --coverage
 ```
````
